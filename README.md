# daryakruk.ai

Сайт-портфолио Дарьи Крук. Переезд со Squarespace на свой стек: быстро, красиво, бесплатно.

- **Astro**: генерирует сверхбыстрый статичный сайт
- **GSAP + Lenis**: анимации, плавный скролл, закреплённые сцены
- **Keystatic**: админка по адресу `/keystatic`, чтобы менять тексты, картинки и проекты без кода
- **Vercel**: бесплатный хостинг, сайт обновляется сам после каждого изменения в GitHub

## Как менять контент

1. Открой `https://www.daryakruk.ai/keystatic` и войди через GitHub.
2. Разделы:
   - **Home page**: первый экран, «обо мне», цифры, проекты на главной, лента визуалов, отзывы, клиенты
   - **Projects (portfolio)**: кейсы. Каждый кейс собирается из блоков (Hero, Video, Text, Step, Gallery и др.), их можно добавлять, удалять и перетаскивать
   - **Site settings**: соцсети, e-mail, ключ формы, тексты кнопок
3. Нажми **Save**. Через 1–2 минуты изменения появятся на сайте.

Форматирование в текстовых полях: `**жирный**`, `_курсив_`, `((текст))` (нарисованный овал).

## Где что лежит

| Что | Где |
| --- | --- |
| Тексты и структура страниц | `src/content/*.json`, `src/content/projects/*.json` |
| Картинки | `src/assets/images/…` (сайт сам сжимает их в WebP нужных размеров) |
| Видео | `public/videos/` |
| Главная страница | `src/pages/index.astro` |
| Блоки кейсов | `src/components/Sections.astro` |
| Анимации | `src/scripts/motion.ts` |
| Админка (поля) | `keystatic.config.ts` |

## Локальный запуск (для разработчика)

```bash
npm install
npm run dev     # http://localhost:4321, админка: http://localhost:4321/keystatic
npm run build
```

## Настройка в продакшене

См. `.env.example`: подключение админки (Keystatic Cloud или GitHub App).
Форма контактов работает через бесплатный сервис web3forms.com. Ключ вставляется в админке: Site settings → Contact form key.
